# 她的小生活 · AstrBot 陪伴插件集

> 三个让 QQ 机器人「像个人」的插件。
>
> 不是拟人话术，是**给她一个自己的生活**。

---

## 这是什么

三个独立插件，可以单独装，也可以一起装：

| 插件 | 做什么 |
|---|---|
| **inner_life** | 内心生活：她有自己的日程、状态、天气，做完事会跟你说一声 |
| **watch_together** | 陪看：你放番，她隔着屏幕一起看，边看边说两句 |
| **draw** | 绘画：她说在画画，你说"给我看看"，她真的画给你 |

---

## 为什么要做这个

市面上的陪伴机器人大多是这样：

```
你：在干嘛
她：在想你呀～
（然后没有下文）
```

问题是——**她没有生活**。

你问她在干嘛，她只能现编一句。下一次再问，又是另一句。

这三个插件想解决的是：

```
她真的在做某件事（有状态、有时长、有结果）
她做的事会影响她的心情
她做完会想跟你说一声
她说在画画，就真的能画出来
```

---

## 核心设计

### 1. 状态是连续的

```
07:30  起床，定今天的计划（3 件事）
09:00  在背中文单词
10:20  做完，跟你说「刚背完一页」
10:20  转去下一个计划：做咖喱
11:00  咖喱做糊了，想说一句
```

不是随机抽一句话，是**按时间推进的生活**。

### 2. 计划是结合天气的

```
今天：三亚，小阵雨 +25°C
→ 计划：听雨写日记 / 烤黄油曲奇 / 听雨发呆
```

下雨天她不会说"去海边散步"。

### 3. 说话有分寸

- 白天可以互动（"汤咸了要不要尝尝"）
- 你在睡觉时只分享（视频、日记），不打扰
- 每天主动消息有软上限

### 4. 她能被你影响

```
你说「我回来了」→ 她去玄关等你
你说「别弄了」→ 她停下手里的事
你说「陪我一会儿」→ 她放下手上的事
```

## 安装

### 前置

- AstrBot >= 4.27
- Python 3.10+
- 一个 DeepSeek API key（状态生成用）
- 一个智谱 API key（视觉/生图用，可选）

### 环境变量

```bash
export ASTBOT_OWNER_QQ="你的QQ号"
export ASTBOT_OWNER_UMO="平台:消息类型:QQ号"
export ASTBOT_DATA_DIR="/AstrBot/data"
export ASTBOT_DB="/AstrBot/data/data_v4.db"
export ASTBOT_CFG="/AstrBot/data/cmd_config.json"
```

### 装插件

把 `plugins/` 下的三个目录复制到 AstrBot 的 `data/plugins/`，重启。

## inner_life：内心生活

**她的状态从哪来？**

```
8 个类别（学习/做饭/画画/家务/娱乐/发呆/出门/休息）
× 每类 6~10 个子场景
→ 随机抽一个
→ LLM 补细节
```

**为什么不全交给 LLM 自由发挥？**

实测过：完全自由生成会退化。

```
全天趴着玩手机
全天卡在同一个字上
全天在做饭
```

模型抓到一个锚点就不放。所以给了骨架，细节留给它。

**天气怎么用？**

```
wttr.in 免费 API
→ 早上定计划时带上
→ 下雨就少出门，天热就多点室内
```

**主动消息什么时候发？**

```
有产物的事（做饭/家务/画画/学习）→ 做完说
没产物的事（娱乐/发呆/出门/休息）→ 做到一半说
```

**为什么？**

```
"煮了锅汤" 这种事，做完说才合理
"在超市逛" 这种事，做到一半说才自然
```

## watch_together：陪看

**原理**

```
你发 /陪看 番名
→ 每 2 分钟读一次电脑截图
→ 视觉模型描述画面
→ 结合番名说一句短评
→ 主动发给你
```

**需要**

- 电脑端定时上传截图（默认 2 分钟一张）
- 一份番剧资料（可选，见 `watch_info.json`）

**示例**

```
她：这小子看着就不太靠谱
她：这奔跑镜头也太有张力了
她：这扑上去是生离死别吧
```

**结束**

```
/陪看结束
或者直接说「看完了」
```

## draw：绘画

**触发方式（两种）**

```
① 她说在画画，你说「给我看看」→ 画
② 你引用她关于画画的消息，说「给我看看」→ 画（最准）
```

**画风**

固定成"速写本上的铅笔稿"：

```
铅笔素描，手绘，速写本上的草图，纸纹质感，
粗糙的铅笔笔触，线条粗细不匀，有橡皮擦过的痕迹
```

不是光滑的 AI 插画，是有手作感的草稿。

**生图**

智谱 CogView-4，复用同一个 key。

## 一些踩过的坑

**① `event.get_group_id()` 在私聊返回空字符串**

```python
if event.get_group_id() is not None:  # 永远为真
if event.get_group_id():              # 正确
```

**② 主动发的消息不进对话历史**

`context.send_message` 只发不记，所以她说"刚学了个新词"，你回"厉害"她接不上。

解决：发完手动写进 `conversations` 表。

**③ 视觉模型的 max_tokens 太小**

GLM-5.3-Flash 是推理模型，200 token 全被 reasoning 吃掉，`content` 返回空。

解决：给到 900。

**④ 在 prompt 里写例子 = 模型会抄**

```
❌ 示例："在煮汤，味道不太对"
→ 每次都煮汤
```

解决：不给例子，或者给场景池。
